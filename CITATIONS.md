## Dataset citation

The implementation uses Fashion-MNIST data. A suitable academic citation is:

Xiao, H., Rasul, K., & Vollgraf, R. (2017). *Fashion-MNIST: a Novel Image Dataset for Benchmarking Machine Learning Algorithms*. arXiv:1708.07747. https://doi.org/10.48550/arXiv.1708.07747

The dataset is available from https://github.com/zalandoresearch/fashion-mnist. Dataset files are not redistributed in this repository.
